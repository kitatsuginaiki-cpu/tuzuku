# v7：14日間の検証計画とロードマップ

v6 の計画（[../redesign/04_validation_plan.md](../redesign/04_validation_plan.md)）を引き継ぎ、v7 で加えた4つの機能について確かめます。

- 積み上げ
- 時間／日数
- キャラクター
- 仲間

**前提**
- 対象は1人（仲間を使う場合は2〜8人）で、期間は14日間です。因果関係は判断できません。
- 決めたいのは、それぞれの機能を「続ける・直す・削る」のどれにするかです。
- 毎日の入力は増やしません。数字はすべて、ふだんの操作から自動で残るものだけを使います。
- 過去（2026-10-07まで）の日別の実績は推定しません。

## 進め方

| 期間 | 設定 | 見ること |
|---|---|---|
| Day 0 | 5つの案から習慣を選びます（例：朝8:00・簿記・読書・部屋・note）。厳しさは「ふつう」、共有はオフ。バックアップを書き出します | — |
| Day 1–7 | キャラクターをオン、厳しさは「ふつう」 | 積み上げ・できない日の組・休みの使われ方 |
| Day 8–14 | 次のどちらか1つだけ変えます。A：厳しさを「きびしい」にする（怒る表情が出る）。B：仲間を2人以上にして、共有をオンにする | 変えた後に、始めた日や再開が変わったか |
| Day 14 | 設定からバックアップ（JSON）を書き出し、下の表で判断します | — |

- A と B を同時に変えると、どちらが効いたか区別できません。8日目以降は1つだけ変えます。
- Supabase の設定がまだなら、B は行わずに A だけにします。

## 指標（すべて端末内のデータから）

| 指標 | 定義 | データ源 |
|---|---|---|
| 習慣ごとのやった日 | 予定の日のうち、やった・小さな一手の日数 | `records`（`habitId`・`kind`・`mode`） |
| 再開までの日数 | 予定の日に2日以上あいたあと、何日目に再開したか | 日付の差 |
| できない日の組の利用 | 組を選んだ回数と、そのうち「その日がゼロにならずに済んだ」回数 | `mode = small`、メモの「こんな日は：」 |
| 休みの使われ方 | 休むと決めた日の数。続けて使っていないか | `kind = rest` |
| 節目 | 到達した節目と、その前後3日にやった日 | `meta.milestonesShown` |
| 表情と行動 | 表情ごとに見ると、その日にやった割合がどうか | 表情は保存していないため、記録から同じルール（`moodFor`）で再計算する |
| 仲間（B のとき） | 届いたスタンプの日に、その習慣をやったか | サーバーの `stamps` と自分の記録 |
| 操作の負担 | 週の見直しの「始めやすさ」（1〜5・任意） | `reviews.ease` |

## 判断の目安（1人のデータなので、機械的には適用しません）

| 観察 | 判断 |
|---|---|
| 積み上げの画面を開いた翌日に、やった日が多い／節目の前後で途切れにくい | 積み上げ：**続ける** |
| 小さな一手で「ゼロの日」を避けられている | できない日の組：**続ける** |
| 休みが3日以上続く／予定の日の半分以上が休み | 休みの扱いを **直す**（理由の任意選択、連続日数の上限） |
| 「きびしい」の期間に、再開が遅れた・アプリを開かない日が増えた | 怒る表情を **削る**、または「ふつう」を上限にする |
| 「きびしい」の期間に再開が早まり、不快感もない（見直しのメモ） | 怒る表情を **続ける**（選択式のまま） |
| スタンプが届いた日にやった割合が高い、または差がない | 仲間：**続ける**（害がない） |
| 仲間に見られることで、記録を盛る・休みを隠すようになった（本人の振り返り） | 共有の項目を減らす（積み上げを隠せるようにする）→ **直す** |
| ある習慣だけ記録がほとんどない | その習慣は「しまう」か、予定の曜日を減らすよう提案する |

## ロードマップ

| 段階 | 内容 | 前提 |
|---|---|---|
| 次 | 本物の Supabase で2台を使い、ログイン・同期・グループを確かめる | 接続先の設定 |
| P1 | 14日検証の集計画面（習慣ごと・期間ごと・表情ごと） | 今は JSON から集計している |
| P1 | 同期の競合を項目単位でマージする（今は LWW） | 2台での同時編集が実際に起きたら |
| P1 | 習慣の並べ替え、きっかけの例をテンプレートから選ぶ | 習慣が5つを超えたら |
| P2 | 任意のリマインダー（Web Push・既定はオフ） | サーバーの送信機能が必要。依存を生まない設計にする |
| P2 | 仲間からの「やろう」を通知で受け取る（1日1回まで） | Web Push が必要 |
| 保留 | ランキング・コメント・連続日数の競争 | 比較や罪悪感で離脱する懸念があるため、入れない方針 |
