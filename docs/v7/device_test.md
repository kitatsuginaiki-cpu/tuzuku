# 実機テスト手順（v7.2・単一端末モード）

この手順は、スマートフォンで「つづく。」を **1台で安全に使い始められるか** を確かめるためのものです。所要時間は 30〜40分（T5 の待ち時間を含む）。

- 対象 URL：https://kitatsuginaiki-cpu.github.io/tuzuku/
- 対象バージョン：**7.2.0 以降**（設定 → 「このアプリについて」の「バージョン」で確認）
- この版では **PC・スマホ間の同期と「仲間」は止めています**。記録はその端末にだけ保存されます。
- 結果は最後の「記録表」に ○ / × / メモ で書き、× があったらその項目の番号と画面のスクリーンショットを送ってください。

> ⚠️ **テストで作った記録の扱い**
> テストのために実際には学習していない記録を作った場合、それは実績ではありません。
> **T0 で書き出したバックアップを、最後の T10 で復元すれば、テスト前の状態に戻ります。**
> 本当に学習した記録を残したい場合は、T10 の復元はせずに、テスト用の記録だけを「記録」画面から削除してください。

## T0. 準備（はじめに必ず）

| 手順 | 期待結果 | 失敗したとき |
|---|---|---|
| 1. Safari（Android は Chrome）で URL を開く | 「今日」の画面が出る | 真っ白なら一度再読み込み。それでも白ければスクリーンショットを送る |
| 2. 設定（右上の歯車）→ いちばん下の「バージョン」を見る | `7.2.0 (xxxxxxx)` と出る | 7.1 以前なら、ページを閉じて開き直す（新しい版の読み込みに1回かかることがあります） |
| 3. 「記録」タブで、簿記3級の積み上げと件数を確認してメモする | 何もしていなければ **17時間36分・0件** | **17時間36分より多い、または心当たりのない記録がある場合は、何も操作せずにスクリーンショットを送る**（実績として扱ってよいか確認します） |
| 4. 設定 →「バックアップをコピー」→ メモアプリに貼り付けて保存（ファイルを保存できる場合は「バックアップを書き出す」でも可） | 「バックアップをコピーしました」と出る。設定の「最後のバックアップ」が今の時刻になる | コピーできない場合は、出てきた文字をすべて選択してコピー |

> 📱 **iPhone の注意**：Safari で開いたときのデータと、ホーム画面に追加したアプリのデータは、**別々に保存されることがあります**。Safari ですでに記録している場合は、手順4のバックアップを、T1 のあとアプリ側で「貼り付けて復元」してください。

## T1. ホーム画面への追加

| 手順 | 期待結果 | 失敗したとき |
|---|---|---|
| iPhone：Safari の共有ボタン（□↑）→「ホーム画面に追加」→ 追加<br>Android：Chrome のメニュー →「アプリをインストール」または「ホーム画面に追加」 | ホーム画面に「つづく。」のアイコンができる | メニューに出ない場合は、ページを一度再読み込みしてから再度 |
| アイコンから開く | アドレスバーのない全画面で開く。iPhone では「ホーム画面に追加して使ってください」の案内が **出ない** | アドレスバーが出る場合は Safari の「ブックマーク」になっている可能性。追加し直す |
| （T0 で記録があった人のみ）設定 →「貼り付けて復元」にバックアップを貼る →「内容を確認する」→「置き換えて復元する」 | T0 でメモした積み上げ・件数と同じになる | 違う場合はスクリーンショットを送る（復元は「直前の状態に戻す」で取り消せます） |

**以降のテストは、すべてホーム画面のアイコンから開いて行います。**

## T2. 学習開始

| 手順 | 期待結果 | 失敗したとき |
|---|---|---|
| 「今日」で習慣が未作成なら、使う習慣を選んで「◯つの習慣ではじめる」 | 習慣のカードが並ぶ。つづきぼし（キャラクター）が出る | 選べない・ボタンが押せない場合はスクリーンショット |
| 簿記3級のカードの「しおりから始める」 | 計測画面になり、残り時間（例 20:00）が減っていく。キャラクターが **目を閉じた集中の顔** | 時間が進まない場合は T5 も実施して結果を送る |

## T3. 学習終了と記録保存

| 手順 | 期待結果 | 失敗したとき |
|---|---|---|
| 1分以上たったら「終える」 | 終了画面に計測した分数が出る | 1分未満なら分数の入力を求められる（正常） |
| 必要なら「時間を修正」で実際の分数にし、「保存して終了」 | 今日の画面に戻り「◯分を積み上げました」。簿記の積み上げが **保存した分だけ** 増える。キャラクターが嬉しそうな顔 | 保存できないと出た場合は、入力が残っているので「もう一度保存する」。それでも失敗なら画面を閉じずにスクリーンショット |
| 「記録」タブ | 記録が1件増えている | — |

## T4. アプリを閉じた後の記録保持

| 手順 | 期待結果 | 失敗したとき |

| 「終える」→ 実際に学習していなければ **「中断」→「記録せず終了」**（または終了画面で実際の分数に修正） | 架空の時間が記録されない | — |

## T6. オフライン状態での記録

| 手順 | 期待結果 | 失敗したとき |
|---|---|---|
| 機内モードをオン → アイコンから開く | 普段どおり開く | 「接続されていません」等が出る場合は、一度オンラインで開いてから再試行（初回の読み込みが必要） |
| 日数型の習慣（例：読書）で「やった」、または簿記を計測して保存 | 記録できる。エラーが出ない | 保存できないと出たらスクリーンショット |
| アプリを完全に終了 → 機内モードのまま開き直す | 記録が残っている | 消えている場合は **重大** |

## T7. インターネット復帰後の動作

| 手順 | 期待結果 | 失敗したとき |
|---|---|---|
| 機内モードをオフ → アプリを開いたまま1分ほど使う | 何も変わらない（同期は止めているので、送信も受信もしない）。エラーや「同期できませんでした」は出ない | 何かエラーが出たら文言を送る |
| 「仲間」タブ | 「仲間と同期は、安全確認のため一時停止中です」と出る | ログイン画面が出た場合は古い版。T0 の手順2へ |

| 手順 | 期待結果 | 失敗したとき |
|---|---|---|
| 設定 →「バックアップをコピー」→ メモに貼る | 「最後のバックアップ」が今の時刻になる | — |
| 設定 →「記録と設定を消去…」→「消去する」 | 「何をつづけますか？」の画面になる | — |

## 自動テストで確認済みのこと（実機では確認していない）

Chromium（PC のブラウザ）でスマホの画面サイズを再現して確認しています。iPhone の Safari・Android の Chrome での動作は、このテストで初めて確認します。

- 計測の時刻計算、一時停止、中断、二重保存の防止、保存失敗時の入力保持
- バックアップの書き出し・コピー・復元・直前の状態に戻す
- 保存できないブラウザでの警告、iPhone の Safari での案内（画面の判定のみ）
- 同期を止めた状態で、サーバーへの通信が 0 件であること（本番と同じビルドで確認）
- v6 からの移行で、記録の件数・分数が変わらないこと
