# 02 現行評価・行動障壁・戦略・機能評価

## 1. 現行（v5）の評価

**優れている点**
- 主操作が1つ（学習を始める）で、未設定でも開始できる。
- 架空データを出さない。基準値（17時間36分）と実記録を分けている。
- 計測が壁時計ベースで、離脱・再読み込みに強い。保存失敗時に入力を保持。
- 次の一歩の保存→ホームへの引き継ぎ、2日空いたら再開表示。

**改善すべき点**
| 指摘 | 根拠 |
|---|---|
| 「きっかけ」がホーム最下部の1行で、ほとんど使われない設計 | 実行意図は if-then 形式・リハーサルで効果が大きい（Sheeran 2025）。いまは if と then が別々の場所にあり、文として結びついていない |
| 「2分だけ始める」が誰にとっても同じ2分 | 代わりの行動は本人が事前に決めるほど、その場の意思決定が減る（コーピング・プランの考え方）。2分の根拠は検証されていない |
| 再開画面は文言が変わるだけで、選べる行動が変わらない | 再開時の障壁（内容が重い・計画が合わない）に対する選択肢がない |
| 計画と実行の比較ができない | 「予定に対する実行率」「きっかけ通りか」のデータがない |
| 見た目が「見出し＋大ボタン＋区切り線」の単調な縦並び | 情報の関係（きっかけ→一手→代わり）がレイアウトに表れていない |
| 「次の一歩」の具体性を支援しない | 「簿記の勉強」のような曖昧な一手では着手の負担が下がらない |

**既存機能の判断**
| 機能 | 判断 |
|---|---|
| 学習開始・タイマー・一時停止・中断・終了 | **維持**（壁時計計測、自動完了なし） |
| 次にやること | **統合・強化** → 「しおり（次の一手）」として終了時の主入力に |
| きっかけ | **統合・強化** → プラン（もし〜なら→一手）の中核に |
| 2分だけ始める | **置き換え** → 本人が決める「小さな一手」（未設定時は2分のまま） |
| 再開ホーム | **強化** → 3つの選択肢＋事実のみの表示 |
| 記録・手入力・編集・削除・バックアップ | **維持** |
| 直近14日の集計 | **統合** → 週の見直しへ（事実の表示） |

## 2. 行動障壁の再定義（仮説）

プロセス：目標を持つ → 機会を見つける → 着手する → 行動する → 終える → 次回に備える → 再び着手する
（COM-B：C=能力、O=機会、M=動機。**いずれも仮説で、本人の中断理由は未特定**）

| 段階 | 想定される障壁 | COM-B | 本アプリでの対応 |
|---|---|---|---|
| 目標を持つ | 簿記3級という目標が大きく、今日の行動に落ちない | C | しおり（具体的な一手）。曖昧な入力には具体化のヒント |
| 機会を見つける | いつやるか決まっていない／予定が変わる | O | プランの「もし〔きっかけ〕」。曜日の予定 |
| 着手する | 何から始めるか迷う／始めるまでが面倒 | C/M | ホームに一手を1つだけ表示、1タップ開始 |
| 着手する | 今日は重い・時間がない | O/M | 事前に決めた「小さな一手」 |
| 行動する | 20分前後で集中が切れる | C | 目標時間を自分で設定。区切りで「続ける／終える」を選ぶ（強制しない） |
| 行動する | 教材アプリへ切り替える | O | 画面を離れても計測継続、終了時に修正 |
| 終える | 記録の入力が面倒 | M | 入力は時間確認＋次の一手（任意）のみ |
| 次回に備える | 次に何をするか書かない／曖昧 | C | しおりの候補（「続き」「復習（解き直し）」）を今日の内容から生成 |
| 再び着手する | 空白後の気まずさ・計画が合わない | M/O | 再開ホーム（失敗表示なし）＋プランを1つだけ変える導線 |

### 検証のための最小限の情報取得
- **毎日の質問はゼロ**。学習の開始・終了時の操作から自動的に取れる事実だけを使う。
- 終了時に**任意の1タップ**：「きっかけ通りに始めた？（はい／ちがうタイミング）」。答えなくても保存できる。
- 週に1回（任意）：「今週の始めやすさ（1〜5）」1問のみ。
- 自動で残す事実：開始方法（しおりから／小さな一手／その他）、アプリを開いてから開始までの秒数、予定曜日か否か、しおりを残したか。**すべて端末内のみ・本人に表示・書き出し可能**。

## 3. 新たなプロダクト戦略

**中心課題**：学習したい気持ちを、「決まった場面で、決まった一手から始める」行動に変え、途切れたときに同じ一手（または小さな一手）から戻れるようにする。

**価値提案**：**「迷わず始めて、しおりを挟んで終わる。」**
本を閉じるときにしおりを挟むように、学習を終えるときに次の一手を残す。次に開いたとき、そのしおりが「もし〔きっかけ〕なら」という自分の計画と一緒に待っている。

**主な体験**
1. 開く → 自分のプラン（もし〜なら → 一手）が文として見える → 1タップで始める
2. 重い日 → 同じ画面の「小さな一手」で始める
3. 終える → 時間を確認し、しおり（次の一手）を挟む
4. 間が空く → 責めない再開画面（しおり／小さく／プランを1つ変える）
5. 週に1度 → 事実だけを見て、プランを1つだけ変える

**差別化**：記録の量やストリークではなく、**開始前の「if-then」と、途切れた後の「戻り方」**を設計の中心に置く（→ 01_research §2-3）。

**中核機能（行動変容）は3つ**：
1. **プラン**（#1 きっかけ＋#3 小さな一手）＝「もし〜なら→一手／できない日は→小さな一手」
2. **しおり**（#2＋#7）＝終了時に次の一手を残し、次回そのまま始める
3. **戻り方**（#4＋#5）＝再開ホームと週の見直し
